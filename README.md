# jonathan.luckins.im

Personal website for Jonathan Luckins, hosted on GitHub Pages.

Live at: [jonathan.luckins.im](https://jonathan.luckins.im)

## Structure

```
/
├── index.html        # Main page
├── assets/
│   └── style.css     # All styles
├── CNAME             # Custom domain
└── README.md
```

## Deploying

Push to the `main` branch of the GitHub repo. GitHub Pages serves the site automatically.
Custom domain is configured via the `CNAME` file and DNS settings pointing to GitHub Pages.

## Adding notes later

Create a `notes/` directory with individual HTML files or a simple index. Update the nav and notes section in `index.html` when ready.
